# demo 01: subject-space Schaefer parcellation

## purpose

This demo shows the subject-space Schaefer parcellation approach used before extracting parcellated fMRI and PET data. In the manuscript workflow, this corresponds to the `BuildParcels_surface` option in the original `script_one.m` pipeline.

The goal is to project group-defined Schaefer atlas labels from fsaverage space to an individual participant's FreeSurfer cortical surface, producing subject-space left- and right-hemisphere annotation files.

## manuscript connection

This demo relates to the subject-space cortical parcellation workflow used throughout the manuscript.

## inputs

This demo requires real structural MRI preprocessing outputs rather than synthetic data.

Required inputs are:

- `subject_id`: FreeSurfer subject/session identifier
- `which_atlas`: Schaefer atlas name, for example `Schaefer400Yeo7`
- `dir_subjs`: FreeSurfer subjects directory containing the participant folder
- `dir_freesurfer`: local FreeSurfer installation path
- `dir_fsaverage_hb`: fsaverage/Schaefer atlas resources from `matlab-utils`
- `dir_hbfssh`: shell scripts from `matlab-utils`, including `hb_aparcfsavg2subj.sh` and `hb_annot2seg.sh`

## outputs

The expected outputs are subject-space surface annotation files for the selected Schaefer atlas:

- left-hemisphere annotation file
- right-hemisphere annotation file
- related parcel-size files, when generated by the helper utilities

The exact output paths are returned in the `param` structure.

## dependencies

This demo depends on FreeSurfer, MATLAB, and helper functions/scripts from:

https://github.com/aitchbi/matlab-utils

In particular, the underlying workflow calls `hb_corticalparc`, which in turn relies on `hb_aparcfsavg2subj.m` and associated shell scripts.

## notes

This demo is intentionally a path-configured template rather than a synthetic-data demo, because subject-space parcellation requires real FreeSurfer surfaces and atlas annotation resources.
